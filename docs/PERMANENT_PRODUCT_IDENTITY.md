# Permanent Product Identity

Owner-approved identity:

```text
Product: Pilgrim Tracker
Android ID: com.enospebrian.pilgrimtracker
Windows company: Enos Pebrian
Current version: 1.0.0+1
Release label: Pilgrim Tracker 1.0.0 Closed Beta Candidate 1
```

The release label is documentation only. Platform version values remain
`1.0.0+1`.

Android package continuity now depends on preserving
`com.enospebrian.pilgrimtracker` and the eventual production signing key.
Changing either after distribution creates upgrade and identity risk.

Windows certificate publisher identity remains a later certificate decision.
No certificate subject or signing credential is implied by the visible company
metadata.
